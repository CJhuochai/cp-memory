# CP Memory Growth Launch Materials Design

## 中文

### 目标

让首次访问 GitHub 仓库的 Codex 用户在首页快速理解 CP Memory 的具体价值，并为后续中英文发布准备可复用、脱敏的演示素材。

### 范围

- 调整中英文 README 首屏，使其先说明“跨会话不忘项目规则、可解释、可纠错”的结果。
- 如实说明审阅提醒当前注入给助手上下文，不是用户界面弹窗。
- 新增中英文 30 秒演示脚本，使用虚构、脱敏规则展示“记录、恢复、纠错”。

### 非目标

- 不改 MCP、Hooks、记忆模型或安装逻辑。
- 不创建图形化审阅界面。
- 不发布帖子、提交外部目录或代表用户与第三方沟通。

### 验收

- 两份 README 信息一致，且首屏包含可验证的使用结果。
- 演示脚本不含真实记忆、路径、账户或客户信息。
- 文档不再声称用户能直接看到当前隐藏的审阅提醒。

## English

### Goal

Help first-time Codex users understand CP Memory's concrete value on the GitHub landing page, and prepare reusable sanitized material for later Chinese and English launches.

### Scope

- Adjust both README hero sections to lead with the outcome: retain project rules across sessions, explain memory, and correct it safely.
- Describe review reminders accurately: they are currently injected into assistant context, not shown as a user-facing popup.
- Add a bilingual 30-second demo script using fictional, sanitized rules to show remember, restore, and correct.

### Non-goals

- No changes to MCP, hooks, memory models, or installation.
- No graphical review UI.
- No external posts, directory submissions, or third-party communication.

### Acceptance

- Both READMEs contain equivalent information and a verifiable usage outcome in the hero section.
- The demo contains no real memories, paths, accounts, or customer information.
- Documentation no longer claims that users directly see the current hidden review reminder.
